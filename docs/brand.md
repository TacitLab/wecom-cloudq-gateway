# CloudAgent Gateway 标志

本次范围为现有后台的字母标志与图标统一，不改变产品命名和页面视觉系统。

## 方向

以 CA（CloudAgent）为字母标志，表达技术工具需要的清晰、稳定和克制。采用紧凑字距，让两字母在小尺寸下形成完整轮廓；保留蓝色体系，不使用渐变、描边、投影或额外装饰。

## 规范

- 原始图形：`web/public/favicon.svg`。侧栏和浏览器 SVG favicon 直接引用同一文件。
- 字形基于 Geist Variable（SIL Open Font License 1.1），字重 780，字距调整为 -125 字体单位；输出为路径，图标无字体依赖。
- 画板：64 × 64；外框圆角：14；文字轮廓宽：49；水平居中，垂直光学上移 0.2。
- 固定颜色：底色 `#246D9D`，字形 `#FFFFFF`。
- 侧栏显示：32 × 32；浏览器图标检查：16、24、32、48 px。
- 深色与浅色界面使用相同的蓝底白字图标。不重新排字、不拉伸、不添加渐变或效果。

## 导出

- `web/public/favicon.svg`：矢量源文件，侧栏与现代浏览器使用。
- `web/public/favicon.ico`：16、32、48、64、128、256 px 的兼容图标。
- `web/public/apple-touch-icon.png`：180 × 180。
- `web/public/brand-icon.png`：512 × 512，可复用的透明圆角图标。

浏览器图标在 `web/index.html` 显式声明，路径使用 Vite 的 `BASE_URL`，支持 `/admin/` 部署。图标引用带版本查询参数；更新图形时同步更新版本，避免浏览器沿用旧缓存。
